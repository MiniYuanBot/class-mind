# Markdown 格式规范

## 一、标题层级

```markdown
## 章节主题

### 核心概念 / 方法

#### 具体细节 / 推导
```

- 最多使用到 `####` 四级标题
- 不使用 `#` 一级标题（避免与文档总标题冲突）
- 每个标题应**语义明确**，便于快速定位知识点

---

## 二、语言与术语规范

### 2.1 语言风格

- **以中文为主**，自然流畅，适合教学
- 使用口语化但专业的表达，如：
  - “也就是说……”
  - “本质上……”
  - “值得注意的是……”
  - “例如……”
  - “类比一下……”

### 2.2 英文术语处理

- 首次出现时：**中文 + 括号英文 + 可选加粗**

  ```markdown
  卷积（Convolution）
  梯度（Gradient）
  端到端（end-to-end）
  ```

- 多次出现时：可直接使用中文，也可中英混用，但保持一致
- 核心术语可适当加粗强调：**反向传播（Backpropagation）**

## 三、内容结构规范

### 3.1 知识点的标准展开顺序

对于每个**核心概念 / 方法**，建议按以下顺序展开：

```markdown
### 概念名称（英文）

**定义**：……
**核心思想**：……
**背景与目的**：……
**数学表达**（如有）：……
**直观理解**：……
```

### 3.2 算法 / 流程的拆解方式

```markdown
**算法名称**的步骤如下：

1. **步骤一名称**
   - 输入：……
   - 操作：……
   - 输出：……
   - 目的：……

2. **步骤二名称**
   - ……
```

### 3.3 对比内容使用表格

```markdown
| 方法 | 优点 | 缺点 | 适用场景 |
| :--- | :--- | :--- | ---: |
| 方法A | 收敛快 | 易过拟合 | 数据充足 |
| 方法B | 稳定 | 计算慢 | 小数据集 |
```

**表格规范**：

- 每个 `|` 左右保留一个空格
- 每行第一个 `|` 后有一个空格，最后一个 `|` 前有一个空格
- 对齐标记：
  - `:---` 左对齐
  - `---:` 右对齐
  - `:---:` 居中对齐

## 四、公式规范（强制）

### 标准模板

```markdown
损失函数定义：
$$
\mathcal{L}(\theta) = -\frac{1}{n} \sum_{i=1}^n \left[ y^{(i)}\log h(x^{(i)}; \theta) + (1-y^{(i)})\log(1-h(x^{(i)}; \theta)) \right]
$$

**符号说明**：
- $n$：样本总数
- $y^{(i)} \in \{0,1\}$：第 $i$ 个样本的真实标签
- $h(x^{(i)}; \theta) \in [0,1]$：模型预测为类别1的概率
- $\theta$：待优化的模型参数

**含义解释**：
该公式计算预测概率分布与真实分布之间的差异，值越小表示模型预测越准确。

**物理/几何意义**：
等价于最小化两个概率分布的交叉熵，使模型输出尽可能接近真实标签。
```

### 公式嵌入方式

- 独立公式：使用 `$$ ... $$` 并独占一行
- 行内公式：使用 `$ ... $`
- 多个对齐公式：使用 `\begin{aligned} ... \end{aligned}`

## 五、互动环节（强制）

每个主要知识点或章节末尾，必须包含：

```markdown
### 常见疑问与解答

**Q1: 为什么使用对数形式而不是直接最小化预测误差？**
> 直接最小化误差（如MSE）在分类问题中会导致梯度消失；对数形式将乘法转化为加法，数值稳定性更好，且对错误预测的惩罚呈指数级增长。

**Q2: 交叉熵损失与最大似然估计的关系是什么？**
> 两者数学等价。最小化交叉熵等价于最大化似然函数，都是在寻找使观测数据出现概率最大的模型参数。
```

- 每章至少 1–3 个 Q&A
- 问题要有实际价值，回答要透彻

## 六、标注与强调规范

### 6.1 重要提示

```markdown
**注**：学习型方法虽然在很多视觉任务中表现更好，但在数据稀缺或实时/嵌入式场景中经典方法仍有价值。
```

### 6.2 易错点标注

```markdown
**易错点**：
- 混淆 softmax 与 sigmoid 的使用场景
- 忘记对输入做归一化导致梯度爆炸
```

## 八、代码与伪代码

### 伪代码示例

```markdown
**训练流程**：

1. **Forward**：由输入计算输出概率与 Loss
2. **Backpropagation**：计算参数梯度
3. **Gradient Descent**：更新参数（SGD / Mini-batch）
4. 重复直到收敛或达到训练轮次
```

### 真实代码（可选）

```python
# 简短示例
for epoch in range(num_epochs):
    for x_batch, y_batch in dataloader:
        pred = model(x_batch)
        loss = loss_fn(pred, y_batch)
        loss.backward()
        optimizer.step()
```
