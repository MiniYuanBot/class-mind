【任务 L2：分节精写（Section Drafting）——为“本批章节”撰写正式笔记正文】

下方“整份结构计划”是 L1 确定的最终文档骨架（所有 `##` 标题都已定稿，禁止改名、增删编号或另起同级新标题；可在节内自由使用 `###`/`####` 与加粗字段组织细节）。你只负责撰写「本批待写章节」，不要写本批之外的任何章节。

写作要求（结合附录 markdown.md 规范）：
1. 对每节：把该节 assigned 页的讲义内容与教师口述**融合成连贯的书面中文正文**——定义、动机/背景、核心要点展开、直观理解（类比/例子）、公式（若讲义或口述出现，须给出 LaTeX + 符号说明 + 含义）、教师强调点（教学语言转述，不要复制口述原句）、易错点（如有），必要时用 Markdown 表格或结构化文字/ASCII 示意表达对比与流程。
2. 自然小标题优先于机械套模板：小节内按内容需要组织（如“定义与组成 / 生命周期 / 触发机制 / 为什么需要 X / 与 Y 的对比”），避免每个知识点都强行塞“定义→思想→背景→直觉”的空模板。若某个维度确实无材料，标注 `[材料未明确]`，不要编造。
3. 讲义与口述的融合规则：讲义只给标题要点、口述给了展开 → 以口述展开为主干、讲义要点为骨架来写；讲义给出了形式化定义/公式而口述在解释 → 定义与公式照讲义写、解释取口述；两者冲突 → 优先讲义并加注。
4. 教师口述中的口语转书面：去掉“okay / right / 那我们现在……”等水词，把口头推演补成完整句子，保留类比与强调（如“老师特别强调：……”）。
5. 教师强调 / 易错 / 记忆点用 **加粗** 或列表突出，正文**禁止**出现：页码、`Slide N`、`<!-- ... -->` 时间戳、“课件原文”“教师讲述”“材料块”等标签与中间产物痕迹。
6. 表格格式：`| 内容 |` 两侧留空格、对齐行用 `:---`；公式独立行用 `$$`、行内用 `$`；每节至少一个可读的收束（小结句或 1–2 个高质量问答，问题真实、回答透彻）。
7. 篇幅：写得扎实但不注水——宁缺毋滥；整批正文请控制在 {{output_budget}} 个汉字以内，按各节重要性分配。
